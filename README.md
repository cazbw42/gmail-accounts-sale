## 二、买 Gmail 账号前，先搞清楚这几个概念

很多人搜「buy gmail accounts」时其实分不清自己要什么，结果买回来一堆用不上的号。我先把几个核心概念捋一遍。

### **PVA 账号 vs 非 PVA 账号**

PVA 就是 Phone Verified Account（手机验证账号）。这类账号注册时通过了真实手机号验证，在 Google 眼里"可信度"更高，不容易触发二次验证。

非 PVA 账号没经过手机验证，价格更便宜，但登录时更容易跳"验证身份"。

### **新号 vs 老号（Aged Account）**

新号就是刚注册不久的账号，权重低，需要"养"一段时间才能正常使用。

老号是注册时间较长的账号（几个月到几年不等），权重高，更稳定，适合直接用于营销、注册社媒、跑广告等场景。老号通常比新号贵不少。

### **全球区 vs 美区 vs 其他区**

Gmail 账号有注册地区之分。美区号最热门，因为很多海外服务（如 ChatGPT、Stripe、TikTok 美区）默认识别美区身份。港区、日区、韩区号也有各自用途。

### **辅助邮箱的作用**

正规渠道出售的 Gmail 通常会带一个辅助邮箱（recovery email）。当主号触发"验证身份"时，可以通过辅助邮箱解锁。这是判断账号质量的重要指标——**没有辅助邮箱的号，基本等于一次性用品**。
